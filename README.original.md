# SPECTRA RENTAL

Sitio web multipágina para alquiler de pantallas LED en Lima.

## Páginas

- `index.html`: inicio
- `pantallas-led.html`: soluciones LED
- `eventos.html`: aplicaciones por tipo de evento
- `proyectos.html`: galería referencial de aplicaciones (no proyectos propios)
- `cotizar.html`: cotizador guiado hacia WhatsApp
- `publicidad-led.html`: publicidad y alquiler de minutos en el Estadio Monumental, visible en la navegación

## Vista local

Abre la carpeta `dist` con Live Server y entra a `index.html`.

## Datos pendientes antes de una publicación comercial definitiva
